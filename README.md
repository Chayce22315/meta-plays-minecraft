# meta plays minecraft

fabric client mod for minecraft java 26.2 that gives meta ai a bridge into your minecraft session.

## current state

this repository is bootstrapped from the official fabric 26.2 example-mod structure and customized for meta plays minecraft.

## target stack

- minecraft java 26.2
- fabric loader 0.19.5
- fabric loom 1.17
- fabric api 0.159.0+26.2
- java 25
- gradle 9.5.1

## roadmap

1. get the client mod loading cleanly
2. add player/world perception
3. add a local ai bridge
4. add structured actions and validation
5. add movement and pathfinding
6. add mining, inventory, and crafting
7. add cooperative gameplay behaviors
